🎬 NVIDIA AI Video Studio

Studio percobaan pribadi • dibuat untuk penggunaan dari HP Android

1. Sambungkan NVIDIA

Masukkan API Key NVIDIA kamu. Kunci hanya disimpan di memori halaman selama tab ini terbuka dan dikirim melalui koneksi HTTPS ke backend milikmu. Jangan bagikan kunci atau screenshot-nya.

Jangan gunakan API Key yang pernah terlihat di screenshot. Cabut kunci lama dan buat kunci baru.

2. Buat cerita dan prompt

Tahap ini memakai endpoint chat NVIDIA. Nama model dapat berubah; jika model tidak tersedia, pilih model teks aktif dari katalog NVIDIA.

3. Hasilkan klip video (Cosmos3 Nano)

Cosmos3 Nano adalah model world-foundation/physical-AI. Hasil animasi cerita mungkin tidak selalu seperti film komersial. Endpoint preview memiliki batas dan dapat berubah.

Catatan

Versi awal ini adalah prototipe: membuat naskah lewat NVIDIA chat API dan menguji text-to-video Cosmos3 Nano. Belum ada otomatisasi multi-scene, penguncian karakter sempurna, penyimpanan cloud, suara, atau editor film otomatis. Fitur tersebut perlu dibangun dan diuji bertahap.
